## Para empezar un chat

Copiar este mensaje y cambiar el ID:

> Lee https://github.com/Daktilega/suno-generation/blob/main/SKILL.md y https://github.com/Daktilega/suno-generation/blob/main/STYLES.md. Este chat trabajará con el estilo 07 — Metal alternativo / groove metal BRC. Genera ahora una canción original: título, Style y letra en inglés, campos separados para copiar en Suno. Elige tema y detalles. Cuando diga «siguiente tanda», conserva el estilo pero cambia temática y diseño melódico, revisando las canciones anteriores de este chat. Si no puedes abrir los archivos, dímelo; no finjas haberlos leído.

Para elegir primero, sustituir la petición de canción por «Muéstrame los estilos y espera a que elija». También puedes descargar los archivos y adjuntarlos a un chat sin acceso web. Un enlace no instala automáticamente una skill ni garantiza acceso desde cualquier chat.

## Qué cambia

La diferenciación se apoya en pulso, instrumento protagonista, voz, hook y dinámica. Se evita repetir el mismo paquete garage/fuzz/voz hablada/xilófono en todas las familias. Los perfiles son propuestas documentadas, pendientes de validación auditiva en Suno; no generan audio desde GitHub.
